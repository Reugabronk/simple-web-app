# Simple Web App
Een kleine Flask-app met een moderne UI, Tailwind CSS en een donker/lichtmodus toggle.

## Installatie
```bash
git clone https://github.com/Reugabronk/simple-web-app.git
cd simple-web-app
pip install -r requirements.txt
python app.py
```
Open vervolgens je browser op `http://127.0.0.1:5000`.

## Features
-   Responsieve layout met Tailwind CSS.
-   Donker/lichtmodus toggle.
-   Eenvoudig formulier dat een bericht toont.

## Toekomstige uitbreidingen
-   CSRF bescherming via Flask-WTF.
-   Dockerfile voor containerisatie.
-   Deploy naar GitHub Pages of Render.
